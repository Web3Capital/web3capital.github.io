从任务定义，到接管与停止。

  1. 定义任务权限

    先确认“流程与工具智能体”的范围、输入、负责人和停止条件。目标结果：让重复流程在明确权限内运行，出现例外时可停止、回滚或转交。

  2. 连接知识工具

    按确认范围完成工作，并记录版本、依赖与未决项。可交付成果：流程模型、工具适配、权限边界、审批点、日志、异常处理与运行指标

  3. 运行受控流程

    执行场景检查，并保留结果、差异与整改记录。验收方法：按成功率、错误恢复、审批执行、幂等性与停止测试验收。

  4. 验证接管与停止

    完成移交，由具名验收方作出通过、有条件通过、整改或停止决定。边界：资金、法律承诺、生产写入与不可逆动作默认关闭，需另行授权。

怎样算完成，由证据和验收决定。

验证检查

  • 目标检查：让重复流程在明确权限内运行，出现例外时可停止、回滚或转交。
  • 产品检查：按成功率、错误恢复、审批执行、幂等性与停止测试验收。
  • 身份、权限、工具调用、日志、失败、接管与停止机制均可测试。

验收标准

  • 完整性：约定交付物均可访问、可复核、可移交。
  • 按成功率、错误恢复、审批执行、幂等性与停止测试验收。
  • 由约定验收方对通过、有条件通过、整改或停止作出具名决定。
